# Heart Disease Risk Predictor

### A Probability and Statistics Approach

This academic project combines statistical analysis of the UCI Cleveland Heart Disease dataset with a Logistic Regression classifier and a Gradio interface.

> **Important:** This application is for educational demonstration only. Its probability and project-defined risk bands are not clinically validated, do not provide a diagnosis, and must not be used to make healthcare decisions.

## Project contents

- `Heart_Disease_Statistical_Analysis.ipynb` — updated notebook containing preprocessing, descriptive analysis, statistical tests, model evaluation, and the Gradio demonstration.
- `app.py` — standalone Gradio application that loads the saved model and scaler.
- `train_model.py` — reproducibly trains the Logistic Regression model and writes `model.pkl` and `scaler.pkl`.
- `model.pkl`, `scaler.pkl` — trained model artifacts generated by `train_model.py`.
- `heart_disease_cleaned.csv` — Cleveland subset data used by the project, including the original target and derived binary disease column.
- `requirements.txt` — Python dependencies.

## Dataset and preprocessing

The Cleveland subset contains 303 records and 14 original attributes. The original `target` values are converted to a binary `disease` label: `0` means no disease and values `1`–`4` mean disease present. The six missing values are in `ca` (4) and `thal` (2); `ca` is median-imputed and `thal` is mode-imputed. The model uses the 13 input attributes and excludes `target` and `disease` from its features.

The application uses the Cleveland encodings: `cp` 1–4, `slope` 1–3, and `thal` 3, 6, or 7.

## Statistical analysis

The notebook includes descriptive statistics, Shapiro–Wilk normality tests, Spearman rank correlation, Mann–Whitney U tests, and Chi-square tests of independence. In the reported analysis, all five continuous variables rejected the normality null hypothesis at the 0.05 level. Seven of eight categorical variables were significantly associated with disease status; fasting blood sugar (`fbs`) was not significant (p = 0.781273). Associations do not establish causation.

## Model and reported evaluation

- Algorithm: Logistic Regression (`max_iter=1000`)
- Split: 80% training / 20% testing
- Split seed: `random_state=42`, stratified by the binary outcome
- Scaling: `StandardScaler`, fitted on training data only
- Reported test accuracy: **86.89%**
- Reported ROC-AUC: **95.13%**
- Confusion matrix: `[[27, 6], [2, 26]]`

These are results from one train/test split and should not be interpreted as a guarantee of performance on other populations.

## Run locally

1. Install Python 3.10 or later.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Generate the model artifacts:

   ```bash
   python train_model.py
   ```

4. Start the Gradio application:

   ```bash
   python app.py
   ```

The application accepts the 13 input attributes and returns a model-estimated probability and a project-defined category: Low (<30%), Moderate (30% to <60%), or High (≥60%). These cutoffs are project choices, not clinical thresholds.

## Run the notebook

Open `Heart_Disease_Statistical_Analysis.ipynb` in Jupyter or Google Colab. Ensure the CSV is available at the path expected by the notebook, then execute cells in order. The notebook's saved model cell writes `model.pkl` and `scaler.pkl` to the current working directory.
